Dustline — a round-based tactical FPS in three.js. 4v4 (you + 3 ally bots vs 4 enemy bots) on an original desert-industrial map with two bomb sites: buy phase, 100-second rounds, win by elimination or bomb plant/defuse, round economy, 4 weapons + armor + 2 grenades, headshots, recoil/spread that punishes firing on the move, and bots that patrol, hold, hunt, cover, plant and defuse. No external assets, no network at runtime — procedural textures and WebAudio synth sounds only.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/ in desktop Chrome.
